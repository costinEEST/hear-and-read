    Import or edit word timings

    One entry per word, in text order: [{"word":"Jó","start":0,"end":0.4}, …]. Include every occurrence of repeated words.

    How highlighting works

    Browser voice: highlighting follows word-boundary events when the chosen voice provides them. If it does not, the current sentence stays highlighted. Voice availability depends on your device.

    Original recordings: words are estimated from text length until you import or manually adjust word timestamps. JW.org imports use publisher verse/paragraph boundaries where available, with estimated words inside each segment.

    Imported timestamps: the player uses the times you provide. Accuracy depends on how those timestamps were made; there is no fixed error guarantee. Forced-alignment output must match this exact text and recording.

    English translations are supplied only for the built-in demos. They are not generated for imported text.
